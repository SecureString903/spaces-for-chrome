Bookmarks bar

Chrome has a single bookmarks bar shared by all windows, so it can only show one Space's bookmarks at a time.

Using the same Chrome profile on several computers? Chrome syncs bookmarks themselves, so bar swaps made here follow you everywhere — your other computers will show the last active Space's bar, with the rest under Other Bookmarks → Spaces. If that's disruptive, choose "Don't manage bookmarks".

Start page

Spaces replaces the New Tab page with a Space-aware start page (clock, search, per-Space link groups, and each Space's homepage redirect). The extras below are optional — nothing leaves your browser unless you turn them on.

With a location set, the start page fetches the forecast from open-meteo.com — your coordinates only, nothing else. A place name is looked up once via open-meteo's geocoder and stored as coordinates.
